# 🌍 Ghurte Jai - AI Travel Planner

An AI-powered travel itinerary generator built with **Laravel** and **Google Gemini 2.0 Flash API**. This application creates personalized travel plans based on user input such as budget, duration, and departure location.

## ✨ Features
- **Dynamic Itinerary:** Generates day-wise travel plans using AI.
- **Location-Based Routing:** Provides transport suggestions from a specific starting point.
- **Budget Management:** Tailors suggestions based on the user's budget (BDT).
- **Localized Content:** Delivers the entire travel plan in Bengali.
- **Modern UI:** Built with Tailwind CSS for a clean and responsive experience.

## 🛠️ Tech Stack
- **Framework:** Laravel 11.x
- **Frontend:** Tailwind CSS, JavaScript (Fetch API)
- **AI Integration:** Google Gemini 2.0 Flash API
- **Backend:** PHP 8.2+
